# Emuchard 

**Emuchard** es una plataforma web orientada a centralizar y organizar enlaces verificados hacia emuladores y distribuidores de ROMs para diversas consolas. 

El objetivo principal es ofrecer un punto de acceso seguro y actualizado, redireccionando a las fuentes oficiales y confiables en lugar de alojar archivos o descargas directas.

> **Estado del proyecto:** En desarrollo activo 

---

## Características Principales

* **Centralización:** Encuentra emuladores y sitios de ROMs organizados por consola en un solo lugar.
* **Redirección Segura:** Enlaces filtrados para garantizar descargas desde sitios confiables y sin publicidad engañosa.
* **Sin Descargas Directas:** La página funciona exclusivamente como un directorio/índice (no aloja archivos de ROMs ni ejecutables).
* **Actualización Automática:** Los enlaces a emuladores y plataformas se mantienen al día conforme surgen nuevas versiones o nuevas fuentes.
